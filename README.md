# Estrelas em Palavras ⭐

Site de poemas onde é possível <br>
**escrever, publicar, buscar e avaliar poemas**, <br>
desenvolvido com **HTML, CSS, JavaScript e Tailwind CSS**.

## Acesso

Ainda sem domínio próprio, pois esta em manutenção.

## Funcionalidades

- Escrever e publicar poemas  
- Buscar poemas  
- Filtrar por tags (#amor, #tristeza, #vida, etc.)  
- Interface responsiva e temática  

## Tecnologias

- HTML  
- CSS  
- JavaScript  
- Tailwind CSS  

## Objetivo

Projeto educacional de front-end para praticar criação de aplicações web.
